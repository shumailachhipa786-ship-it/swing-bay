SWINGBAY SOCIAL WEBSITE
=======================
Open index.html in a modern browser.

Included:
- Responsive one-page premium club website
- Supplied SwingBay Social logo
- All supplied image assets
- Pricing, food/menu, events/packages, players/bays, play time, food credits and descriptions from the supplied Excel workbook
- Interactive menu filtering and food gallery
- 3D/tilt hero effect, reveal animations and neon visual system
- Demo bay-booking calculator using workbook pricing rules

Important:
The supplied workbook did not contain venue opening/closing hours, street address, phone, email, or a live reservation endpoint. The website therefore does not invent those details. Pricing windows (before/after 5 PM) are shown exactly as supplied.

To deploy: upload the folder contents to Netlify, Vercel, GitHub Pages, cPanel/public_html, or another static host.
